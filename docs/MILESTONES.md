# Milestones and Exit Gates

## M0 Truth
Exit when:
- official wording stored;
- ten-language candidate matrix exists;
- licence blockers known;
- one low/mid Android inference test succeeds.

## M1 One complete offline loop
Exit when two phones execute PTT -> STT -> bundle -> transport -> TTS -> ACK without internet.

## M2 Ten-language credibility
Exit when every required language has an evaluated STT and TTS path.

## M3 Safety-aware messages
Exit when critical fields have explicit detection, confirmation, scoring, and UI.

## M4 Resilient delivery
Exit when fragmentation, queue, replay, expiry, relay, and store-forward are tested.

## M5 Scientific evidence
Exit when benchmark tables, routing baselines, ablations, and confidence intervals are reproducible.

## M6 Competition-ready
Exit when live demo, fallback recording, documentation, licence inventory, architecture pitch, and judge Q&A are complete.
