# Dataset and Corpus Plan

## Candidate public resources

Project research has identified relevant families including:
- IndicVoices;
- IndicVoices-R;
- IndicSUPERB;
- FLEURS;
- IIT Madras multilingual Indic TTS resources;
- Common Voice;
- selected OpenSLR corpora.

Every exact version must be audited for licence, redistribution, language coverage, and train/test overlap before use.

## Syntax6 field benchmark

Purpose: evaluation, not necessarily training.

Suggested attributes:
- 5–10 speakers/language where feasible;
- varied age/gender/accent representation;
- multiple microphones/devices;
- quiet and noisy conditions;
- alerts, directions, numbers, negations, times, locations;
- spontaneous and read speech;
- code-switching samples.

## Data governance

- consent;
- speaker IDs pseudonymized;
- no accidental upload of private recordings;
- documented retention;
- speaker-disjoint test split;
- test set never used for model tuning.
