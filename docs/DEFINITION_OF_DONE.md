# Definition of Done

## Competition ready

- [ ] Fully offline two-phone loop works.
- [ ] All ten languages have verified STT and TTS paths.
- [ ] Model/code/data licences documented.
- [ ] Low/mid-range hardware measured.
- [ ] WER/CER/CFA per language reported.
- [ ] TTS intelligibility tested.
- [ ] P50/P90/P95 latency reported.
- [ ] APK/model/RAM/CPU/energy metrics recorded.
- [ ] Semantic bundle versioned and bounded.
- [ ] Authentication/integrity/replay protection implemented.
- [ ] ACK semantics distinguish device receipt from human acknowledgement.
- [ ] BLE/local Wi-Fi direct path repeatable.
- [ ] Multi-hop/store-forward measured if claimed.
- [ ] Critical uncertainty has safe UX.
- [ ] Fragmentation and malformed inputs tested.
- [ ] Process death/restart tested.
- [ ] No raw private speech logging by default.
- [ ] Baselines and ablations exist.
- [ ] Results trace to experiment IDs and git commits.
- [ ] Demo fallback video exists.
- [ ] Team can explain limitations honestly.
