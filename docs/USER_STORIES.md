# User Stories

## Responder

As a responder, I want to hold one large button and speak in my language so I can communicate while moving.

Acceptance:
- works offline;
- clear recording state;
- transcript visible;
- can cancel before send.

## Receiver

As a receiver, I want a message spoken aloud so I do not need to read the screen.

Acceptance:
- local TTS;
- exact text visible;
- replay available;
- priority clear.

## Critical instruction sender

As a sender, I want uncertain numbers and negations highlighted so I do not accidentally transmit dangerous information.

## Relay participant

As a relay participant, I want to help carry encrypted messages without exposing their content or draining my battery without limit.

## Field lead

As a field lead, I want to know whether a message was merely transferred, reached the destination device, or was acknowledged by a person.

## Judge/researcher

As an evaluator, I want real stage metrics and reproducible test metadata so claims can be verified.
