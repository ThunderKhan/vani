# Licensing and Provenance

## Rule

“Open source” must be verified independently for:
- application code;
- runtime;
- model architecture code;
- model weights;
- training/evaluation data;
- tokenizer/text resources;
- fonts/voices/assets.

A downloadable model is not automatically redistributable.

## Required model manifest fields

```yaml
name:
version:
source:
code_license:
weights_license:
dataset_provenance:
redistribution_allowed:
commercial_use:
derivatives:
checksum:
conversion_script:
notes:
```

## BitChat boundary

BitChat is architectural inspiration only unless a deliberate, licence-compatible reuse decision is documented.

Any direct GPL code reuse can affect distribution obligations and must be approved explicitly.

## NOTICE

Maintain attribution and third-party notices in a machine-readable inventory plus human-readable NOTICE.
