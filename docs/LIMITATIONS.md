# Limitations

MeshVoice does not:
- create connectivity where no local path/contact exists;
- guarantee delivery;
- preserve speaker identity or emotion;
- guarantee ASR correctness;
- replace public emergency radio systems;
- bypass Android DND or emergency audio rules;
- provide global anonymity;
- solve RF jamming;
- make every Android vendor behave identically;
- make translation error-free;
- turn a short-range radio into long-range radio without relays/bridge.

The system is most defensible when it exposes these limitations and measures their practical impact.
